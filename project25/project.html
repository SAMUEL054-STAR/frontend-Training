The 50/50 logic

Math.random() gives a number from 0.0 to 0.999...
Exactly half of all possible values are below 0.5.
So Math.random() < 0.5 is true 50% of the time.

This is a boolean expression — it is either true or false, and we use it directly in an if/else.
