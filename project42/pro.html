REGULAR EXPRESSIONS (REGEX)

/[A-Z]/.test(str)

true if str contains any uppercase letter

/[0-9]/.test(str)

true if str contains any digit

/[^a-zA-Z0-9]/.test(str)

true if str contains a symbol

A regex is a pattern between two slashes. /.test() returns true or false.
