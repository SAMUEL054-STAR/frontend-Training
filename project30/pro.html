The KEY new skill — creating elements

document.createElement("li") — creates a new <li> in memory.
element.innerHTML = "..." — puts content inside it.
list.appendChild(element) — adds it to the page.
element.remove() — deletes it from the page.

This is how every dynamic list in the real world is built.
